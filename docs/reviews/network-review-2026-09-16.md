## Security conclusions

Remote callers can reach native QUIC/TLS, discovery and negotiated protocol parsers. Resource
starvation candidates therefore apply to a hostile boundary even when a particular external
Lodestar deployment cannot be verified here. Added protections bound handshake allocation,
negotiation, incomplete requests, response writes, validation, retained identities and recovery
promises. Tests exercise rejection, timeout, cleanup and generation reuse, not just happy paths.

Finite tables still have finite flood tolerance. Challenge-table expansion does not solve a
sustained spoofed DiscV5 flood. Retry validates return paths, not honesty. Evicting retained bans
trades retention for fresh admission. RSA/P-521 certificate keys remain unsupported. Fixed bridge
payload reservations still have the memory cost described in F291. Direct-peer gossip send
timeouts now get one delayed retry; negotiation failure still requires new inbound evidence.

See [architecture](../network-architecture.md), [threat model](../../THREAT_MODEL.md) and
[implementation map](../security/IMPLEMENTATION_MAP.md) for the resulting contracts.

resolving its promise. This also preserves late terminal pulls for successful copied chunks.

matrix on both presets. The mainnet ReleaseSafe production addon was restored with fault injection disabled;
its exports contain no network test hooks. Both selected production lifecycle smoke tests
passed, including live-resource worker termination. No generated spec sources or native
build outputs were edited manually. This validation covers the review checkpoint on `feat/network`.
